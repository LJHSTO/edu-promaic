第三周 10 个用户故事、交互原型、技术方案和两周学习计划经 PR #10 合入 main。本地 20 项测试及该 PR 的四组 Windows/Linux、Node.js 22/24 检查通过；教师确认和 320px 补验仍待进行。

## 原因与改进

先前交付检查覆盖代码、文档和 PR，没有把 Projects 卡片同步列入完成检查。自学计划中的子目标与 GitHub Milestones 也没有明确对应。公开页面不能显示可确认的 Workflows 设置，不能把历史配置说明直接当作本轮验证。

| 行动 | 跟踪责任 | 检查条件 | 当前状态 |
|---|---|---|---|
| 当前任务补负责人和真实 Milestone | LJHSTO | #7/#8/#9/#11 元数据可查 | 已实际修改 |
| 补当前卡片、核对关闭/合并自动移列 | LJHSTO | 五列中包含当前工作，Workflows 有可核验记录 | #11 开放，待可编辑 Projects 会话 |
| 新 Issue 进入看板，防止再次遗漏 | LJHSTO 组织认领 | Auto-add 或实际人工补录；新增后复查 | 待设置并验证 |
| 保留部分修复的未完成状态 | PR 提交者与维护者 | 部分处理用 Refs，不把 Issue 提前关闭 | 本轮文档 PR 采用此规则 |
