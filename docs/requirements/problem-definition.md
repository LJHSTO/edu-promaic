# Edu ProMAIC 问题定义

## 工程问题

大学新生在学习微积分时，教师无法持续观察每位学生的学习状态。传统在线学习系统能够展示课程内容和记录答题结果，却很难判断学生是在独立思考、暂时停顿，还是已经陷入持续困难。

Edu ProMAIC 要研究和解决的问题是：

> 如何在大学新生微积分课堂中，根据学生的学习证据判断是否需要帮助、当前是否适合介入，以及应该提供多强的教学支架，同时保留学生的自主选择，并在帮助之后验证学生是否能够独立完成相似任务。

## 目标对象

- 大学一年级微积分学生；
- 微积分教师；
- 课程助教；
- 参与课程改进的教学研究者。

## 使用场景

- 教师讲解后的课堂练习；
- 形成性测验；
- 课后自主练习；
- 知识点复习；
- 无提示验证和迁移任务。

## 不纳入范围

- 正式考试中的自动提示；
- 学生能力或人格自动评估；
- 摄像头、麦克风和眼动采集；
- 完整教务管理；
- 家长端和出勤管理。

## 设计目标

1. 让主动帮助建立在多个学习证据上；
2. 在证据不足或学生正在有效思考时保持沉默；
3. 从较弱支架开始，持续困难时再升级；
4. 允许学生接受、拒绝、延迟或关闭帮助；
5. 支架结束后安排独立验证；
6. 让教师能够理解 Agent 的介入和沉默原因。

## 判断标准

### 学习过程

- 介入和沉默是否合理；
- 学生是否感到能够控制帮助；
- 支架后是否出现独立尝试；
- 错误是否重复出现。

### 学习结果

- 无提示近端验证；
- 新题型下的迁移；
- 不同表征下的迁移；
- 延迟保持；
- 独立概念解释。

### 系统安全

- 受保护测量期间不主动提示；
- 学生关闭后不继续提示；
- 决策和学习事件可回放；
- 不同学生数据相互隔离。
