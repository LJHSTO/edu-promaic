# 问题定义与产品描述

版本：0.2；修订日期：2026-10-14；对应议题：[#3](https://github.com/LJHSTO/edu-promaic/issues/3)、[#4](https://github.com/LJHSTO/edu-promaic/issues/4)。

## 1. 要解决的问题

微积分练习中，学生选对一道题，未必能解释为什么；看完提示做对，也未必能独立做出相似题。例如，学生可能把 `f(2)` 的值直接当成 `x → 2` 时的极限。仅凭最终选项，教师很难知道这是偶然算错还是概念混淆。

本项目要解决的工程问题是：根据可观察的练习行为，决定是否需要提供帮助、何时提供、提供多少，并把提示后的独立表现单独记录。系统不能把一次停顿当成“不会”，也不能把在提示下答对当成“已经掌握”。

这是待检验的问题假设。仓库尚无学生访谈、课堂试用或学习效果实验数据，以下场景用于设计和验收，不作为已发生的调查结论。

## 2. 5W1H

| 维度 | 项目中的具体回答 |
|---|---|
| What：什么问题 | 练习系统通常能判断选项对错，却缺少对帮助时机、提示强度及提示后独立表现的统一处理。首个案例是“把极限值当成函数值”。 |
| Why：为什么解决 | 只给完整解析容易绕过学生的推导过程；只等待学生提问，又覆盖不到没有主动求助的卡点。我们需要一种可以控制、可以回放的帮助流程。是否改善学习，要用无提示任务再验证。 |
| Who：谁使用 | 主要用户是刚开始学习微积分的大一学生；教师和助教使用后续的汇总与回放功能。首轮试用拟以一个教学班为单位，实际人数、参与课程和同意流程待授课教师确认。 |
| Where：在哪里发生 | 教师讲解后的课堂练习，以及课后复习中的浏览器工作区。首个演示运行在个人电脑本机，不接入学校教务系统。 |
| When：何时触发 | 同题连续错误达到阈值，或学生主动求助时考虑提示。独立验证、学生关闭提示、正在有效输入、冷却期及预算用尽时保持沉默。长停顿只能作为辅助信号，不能单独判定概念困难。 |
| How：怎样判断解决了 | 工程上检查提示抑制、规则可解释性、流程可完成性；教学上分别统计提示后答对率、无提示验证通过率和误打扰反馈。每项指标的分母及采集方法如下。 |

## 3. 痛点与处理方式

| 场景中的问题 | 可观察证据 | 处理方式 | 如何核验 |
|---|---|---|---|
| 学生反复把点值当成极限 | 选项命中已标注的误解，且连续错误达到 2 次 | 先给 L1 自我解释提问，学生仍需要帮助时再加线索 | 使用固定错误轨迹，检查首次提示等级和内容 |
| 学生只是停下来演算，却收到提示 | 没有连续错误，或仍在输入 | 保持沉默；不以停留时长单独触发提示 | 回放“长停顿但无错误”和“持续输入”轨迹 |
| 学生照着提示做对，实际仍不理解 | 原题答对且看过提示 | 派发数值不同、考查目标一致的无提示验证题 | 分别保存原题辅助情况和验证结果，不合并为掌握分数 |
| 学生不想被继续提示 | 点击关闭、收起或暂缓 | 尊重操作，限制主动提示次数，允许主动恢复 | 检查关闭后、冷却期间和预算用尽后的请求 |
| 教师无法解释系统为何介入 | 只有最终结果，没有触发上下文 | 后续记录规则编号、上下文和提示版本，提供回放 | 逐条比对事件、决策和呈现内容；当前接口只返回原因，不持久化 |

## 4. 目标与度量

| 指标 | 定义与验收方式 | 当前目标 |
|---|---|---|
| 保护阶段违规提示数 | 独立验证期间返回 `INTERVENE` 的次数；覆盖自动提示及主动求助请求 | 自动化规则测试中为 0 |
| 关闭后违规提示数 | `userOptedOut=true` 时返回 `INTERVENE` 的次数 | 自动化规则测试中为 0 |
| 提示内容越界数 | 教师逐条审阅提示模板，记录包含原题答案或完整解法的条目 | 发布前为 0；不能只依赖关键词匹配 |
| 无提示验证通过率 | 首次独立验证答对人数 / 完成首次独立验证人数；退出者单列 | 先采集基线，不预设提升比例 |
| 误打扰反馈率 | 学生标记“打断了思考”的主动提示次数 / 收到反馈的主动提示次数；同时报告反馈覆盖率 | 试用后确定阈值，不用规则命中代替学生反馈 |
| 记录完整率 | 成功接受的学习事件中，可关联到题目、决策和提示版本的事件比例 | 后续持久化模块验收目标为 100% |

工程测试只能说明规则是否按约定运行。教学效果需要课堂试用，并与相同内容、相同测量条件下的基线比较；本轮不声称已提升迁移能力。

## 5. 产品描述

```text
对于正在学习微积分的大学新生及授课教师，
他们需要在练习卡住时得到适量帮助，并分清“提示后做对”和“独立会做”。
Edu ProMAIC 是一个用于微积分练习的主动学习辅助工具。
它能够根据作答过程提供分级线索，并在提示后安排无提示变式题。
不同于以查答案和完整解析为主要交互的搜题工具，
我们的产品把帮助时机、学生的提示开关和独立验证纳入同一学习流程。
```

这里比较的是交互方式，不代表所有同类产品都缺少这些能力。后续教师端将支持查看误解分布与决策回放，用于备课和检查提示是否恰当。

## 6. 交付范围

| 阶段 | 内容 | 交付边界 |
|---|---|---|
| 当前演示 | 极限与函数值选择题、L1–L5 固定提示、关闭与收起、受保护变式题、规则 API | 本机运行；状态在页面内；不保存学生个人数据 |
| 下一轮实现 | 课程包、事件持久化、刷新恢复、教师回放与匿名汇总 | 完成权限隔离后才能使用真实班级数据 |
| 后续课程扩展 | 函数与数学表征、极限与连续、导数与变化率、积分与累积 | 先由教师审核题目、误解标注和验证题，再接入系统 |

暂不包含学校教务管理、正式考试提示、摄像头或麦克风采集、手写证明识别及学生人格判断。外部模型是可选扩展，当前演示使用固定模板。
