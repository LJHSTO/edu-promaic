# 问题定义与产品描述

版本 0.3，修订于 2026 年 11 月 25 日。 [问题定义 #3](https://github.com/LJHSTO/edu-promaic/issues/3) · [产品范围 #4](https://github.com/LJHSTO/edu-promaic/issues/4)

## 1. 要解决的问题

大一微积分翻转课堂把概念阅读和基础练习放在课前，把讨论和应用放在课上。以“函数值与极限”为例，学生可能把 `f(2)` 的值直接当成 `x → 2` 时的极限。教师需要在上课前知道哪些学生尝试过验证、哪些在新题中仍选择点值，以便安排概念对比活动。

知点记录学生在练习和无提示验证中的作答，用连续错答和主动求助触发分级提示，向教师展示练习辅助情况、首次验证结果与误选记录。教师可据此设计“改变点值、保留两侧趋势”的课堂活动。

## 2. 5W1H

| 维度 | 项目中的具体回答 |
|---|---|
| What：什么问题 | 练习系统通常能判断选项对错，却缺少对帮助时机、提示强度及提示后独立表现的统一处理。首个案例是“把极限值当成函数值”。 |
| Why：为什么解决 | 只给完整解析容易绕过学生的推导过程；只等待学生提问，又覆盖不到没有主动求助的卡点。我们需要一种可以控制、可以回放的帮助流程。是否改善学习，要用无提示任务再验证。 |
| Who：谁使用 | 大一微积分学生完成预习，授课教师发布任务、查看准备度并安排课堂活动。 |
| Where：在哪里发生 | 学生课前在浏览器预习，教师在课前查阅会话和作答。演示使用匿名课堂，机构配置按班级开放。 |
| When：何时触发 | 同题连续错误达到阈值，或学生主动求助时考虑提示。独立验证、学生关闭提示、正在有效输入、冷却期及预算用尽时保持沉默。长停顿只能作为辅助信号，不能单独判定概念困难。 |
| How：怎样判断解决了 | 工程上检查提示抑制、规则可解释性、流程可完成性；教学上分别统计提示后答对率、无提示验证通过率和误打扰反馈。每项指标的分母及采集方法如下。 |

## 3. 痛点与处理方式

| 场景中的问题 | 可观察证据 | 处理方式 | 检查方法 |
|---|---|---|---|
| 学生反复把点值当成极限 | 选项命中已标注的误解，且连续错误达到 2 次 | 先给 L1 自我解释提问，学生仍需要帮助时再加线索 | 使用固定错误轨迹，检查首次提示等级和内容 |
| 学生只是停下来演算，却收到提示 | 没有连续错误，或仍在输入 | 保持沉默；不以停留时长单独触发提示 | 回放“长停顿但无错误”和“持续输入”轨迹 |
| 学生照着提示做对，实际仍不理解 | 原题答对且看过提示 | 派发数值不同、考查目标一致的无提示验证题 | 分别保存原题辅助情况和验证结果，不合并为掌握分数 |
| 学生不想被继续提示 | 点击关闭、收起或暂缓 | 尊重操作，限制主动提示次数，允许主动恢复 | 检查关闭后、冷却期间和预算用尽后的请求 |
| 教师需要判断课堂上优先处理什么 | 练习与验证的首次结果及点值误选 | 汇总验证提交与首次通过，按会话回看作答和提示 | 用一组错答、提示和重试操作核对教师数据 |

## 4. 目标与度量

| 指标 | 定义与验收方式 | 当前目标 |
|---|---|---|
| 保护阶段违规提示数 | 独立验证期间返回 `INTERVENE` 的次数；覆盖自动提示及主动求助请求 | 自动化规则测试中为 0 |
| 关闭后违规提示数 | `userOptedOut=true` 时返回 `INTERVENE` 的次数 | 自动化规则测试中为 0 |
| 提示内容越界数 | 教师逐条审阅提示模板，记录包含原题答案或完整解法的条目 | 发布前为 0；不能只依赖关键词匹配 |
| 无提示验证通过率 | 首次独立验证答对人数 / 完成首次独立验证人数；退出者单列 | 先采集基线，不预设提升比例 |
| 误打扰反馈率 | 学生标记“打断了思考”的主动提示次数 / 收到反馈的主动提示次数；同时报告反馈覆盖率 | 试用后确定阈值，不用规则命中代替学生反馈 |
| 线索可追溯性 | 已生成的课堂线索中，能从会话追溯到学习阶段、工具和课包引用的比例 | 引用均可回链，课程无材料时标明固定提示回退 |

工程测试检查规则执行；课堂试用比较相同内容和测量条件下的独立作答、迁移表现与学习体验。

## 5. 产品描述

知点是面向大一微积分翻转课堂的课前准备度工具。教师发布单节预习任务。学生查阅材料、按需获取练习提示，并通过新题独立验证。教师在课前查看首次通过情况和作答回放，选定课堂讨论题。

## 6. 交付范围

| 阶段 | 内容 | 交付内容 |
|---|---|---|
| 当前课堂 | 发布一节预习任务、带出处的 L1–L5 线索、受保护的变式题、教师汇总和回放 | 支持刷新与重启恢复，提示经过课包检索、图谱扩展和工具校验 |
| 机构试用 | 身份系统接入、班级权限与课程内容审核 | 使用受保护配置，完成真实机构和授课教师验收后开放试用 |
| 后续课程扩展 | 函数与数学表征、极限与连续、导数与变化率、积分与累积 | 先由教师审核题目、误解标注和验证题，再接入系统 |

## 产品架构演进

当前微积分案例向通用学习工作台扩展：保留可控帮助与独立验证，让学生从判断依据、介入时机、支持起点、显示位置、控制方式和帮助后继续六方面设置偏好。课程知识通过 RAG 为当前活动提供出处明确的线索。学科包承载不同课程的知识、活动、题目和工具；详细设计见[技术架构](../software/architecture.md)。
