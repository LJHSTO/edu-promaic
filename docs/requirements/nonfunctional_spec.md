# 非功能需求规格说明书

版本：0.2；修订日期：2026-10-13；对应议题：[#6](https://github.com/LJHSTO/edu-promaic/issues/6)。

本文件按课程采用的 URPS（可用性、可靠性、性能、支持性）组织，并补充隐私与教学内容边界。以下数字是验收目标，不是实测结论。工程检查、课堂体验与学习效果分开验收，未完成的项目不标成达标。

## 1. 环境与测试口径

- 当前演示：Node.js 22 及以上，现代 Chrome / Edge 浏览器；Windows、Linux 由 CI 执行检查。其他浏览器须另做兼容验证。
- 性能目标的基准环境：4 核 CPU、8 GB 内存、单个 Node.js 进程、本地网络；不调用外部模型，先预热 100 次，再测 1,000 次请求。记录操作系统、Node.js 版本和原始耗时，报告 P50 / P95 / P99，不能只报平均值。
- 并发目标：30 个虚拟学生各每 5 秒提交一次，持续 10 分钟；扩展到 200 人前另做容量评估。本轮不以“200 人同时在线”作为已经具备的能力。
- 提示安全和课堂试用须有教师审核与参与同意；自动化测试只能验证确定性的流程约束。

## 2. 需求与验收

| 编号 | 属性 | 明确要求 | 验证方法 | 当前状态 |
|---|---|---|---|---|
| NFR-1 | 可用性：上手 | 用户无需安装插件，打开本地服务即可完成练习和验证。试用时至少 8/10 名首次用户在 5 分钟内完成流程，不依赖开发者代操作 | 记录任务完成时间、失败原因及样本招募条件 | 流程可演示；新用户测试待进行 |
| NFR-2 | 可用性：低打扰 | 提示不使用阻塞弹窗、不主动抢焦点；可收起和关闭。320 px 及以上视口无横向滚动；键盘可完成主要操作 | 桌面与窄屏走查、Tab 操作、焦点检查 | 本轮浏览器检查 |
| NFR-3 | 可靠性：失败反馈 | 决策请求 3 秒超时，显示中文说明并保留已选答案；按钮恢复可用。同一次失败提交不重复增加错误数 | 模拟超时、断网、非 JSON 返回及 HTTP 500 | 本轮实现与异常走查 |
| NFR-4 | 可靠性：恢复 | 后续刷新或短时断网恢复当前题目、已确认提交及保护阶段；补传去重。客户端不能通过重载解除保护阶段 | 重启浏览器、乱序补传、重复事件；与服务端状态比对 | 后续；当前刷新会重置 |
| NFR-5 | 安全与隐私 | 上线前区分学生、教师和维护者；学生仅访问自己记录，教师仅访问授权班级。匿名 ID 使用随机标识，不以无盐学号哈希宣称匿名；身份映射单独受控保存 | 跨学生、跨班级访问测试；导出字段审阅 | 后续；当前默认本机且不采集身份 |
| NFR-6 | 安全与隐私 | 最小化采集，不保存原始按键、草稿文本和姓名学号。试用事件保存 30 天后删除，需延长时重新说明用途并取得同意；研究导出必须再做识别风险评估 | 字段白名单、过期删除测试、导出审阅 | 保存期限为试用建议，待教师确认；当前无持久化 |
| NFR-7 | 支持性：可追踪 | 后续每个已确认事件可关联会话、题目、规则版本及提示版本，包含沉默记录；写入失败返回错误，不假装成功 | 注入写入失败，核对事件数、决策数和顺序 | 当前有规则原因；持久化未实现 |
| NFR-8 | 教学边界 | 保护阶段所有自动与主动求助请求均返回 L0；已关闭提示同样返回 L0。固定提示经人工审核，不含原题结果或完整解法 | 组合规则测试、逐模板人工评审；后续增加服务端保护状态测试 | 规则已实现；教师评审待进行 |
| NFR-9 | 性能：计算 | 基准环境中单次纯规则决策 P95 ≤ 10 ms | 使用高精度计时，固定输入批次，记录样本数与分位数 | 待专项基准测试 |
| NFR-10 | 性能：服务 | 上述 30 用户负载下，决策接口 P95 ≤ 200 ms，非预期 5xx 比例 < 1%；区分网络耗时与规则计算耗时 | 负载测试报告，统计状态码与延迟 | 待负载测试 |
| NFR-11 | 支持性：可维护 | 决策逻辑无网络、文件或浏览器依赖；阈值可配置且校验合法性；新增题目后不修改沉默规则 | 模块依赖走查、参数测试；后续课程包加载测试 | 规则分层已实现；课程包后续 |
| NFR-12 | 支持性：可测试 | 默认测试命令覆盖单元与集成；每条保护规则、阈值边界和组合优先级有案例；CI 在 Node.js 22、24 的 Windows / Linux 环境执行 | 检查测试案例和 Actions 结果；有需要时再测覆盖率 | 本轮提供 CI；不宣称 100% 覆盖 |
| NFR-13 | 输入防护 | JSON 请求体最多 16 KiB；类型、范围与 Content-Type 不合法返回明确 4xx，不执行评估；静态路由只开放演示资源 | 非法 JSON、字符串布尔值、负数、超限体与路径访问集成测试 | 本轮实现 |
| NFR-14 | 可选模型可靠性 | 模型扩展上线时，3 秒超时即使用已审核固定模板；模型不可修改验证状态、输出未经审核内容或直接访问学生身份 | 模型服务故障注入及内容审阅 | 未接入，后续启用前验收 |

## 3. 结果如何记录

每项验收保留执行日期、环境、样本数、命令或操作步骤、实际结果与限制。测试通过只对应已执行的案例。性能、用户满意度、课堂迁移与保持尚未采集，不用“已达标”“准确率极高”等字样代替证据。
