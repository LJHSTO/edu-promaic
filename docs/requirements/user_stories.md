## 2. 用户故事与详细验收

### US-01 看清当前任务

作为一名刚开始学习微积分的学生，我想直接看到题目、目标和本轮路线，以便知道先做什么、何时会获得帮助。

Must；0.5 人日；FR-5.1；原型可演示。

- Given 新开原型且未作答，When 页面加载，Then 显示题目、三项选项、提交按钮和学习路线，当前步骤为独立尝试。
- Given 没选答案，When 提交，Then 行内提醒先选择答案，结果不跳转、不请求提示。
- Given 320 px 视口，When 操作，Then 页面无横向滚动，主要操作能由键盘到达。

### US-02 获得适度错误反馈

作为一名学生，我想选错后继续尝试，反复错误时再得到第一层帮助，以便保留自主思考机会。

Must；0.5 人日；FR-1.1、FR-2.1、AC-01；原型可演示。

- Given 新练习、提示开启且无抑制条件，When 首次提交任一错误选项，Then 反馈错误且不显示线索。
- Given 同题已成功提交一次错误，When 再次提交错误，Then 显示 L1 自我解释问题，不直接给原题答案。
- Given 只有长停顿而无连续错误，When 调用规则 API，Then 保持沉默；页面不伪称已采集草稿输入。

### US-03 逐层请求并查看来源

作为一名学生，我想按需逐层获取线索并了解来源，以便理解思路而不直接照抄答案。

Must；0.5 人日；FR-3.1、FR-3.3、AC-03；固定模板可演示，教师审核待进行。

- Given 新练习且提示开启，When 主动求助，Then 首次为 L1，再次按 L2–L5 递进，到 L5 后不越级。
- Given 已有线索，When 展开来源说明，Then 看见固定模板来源、版本和待审核状态，不显示虚构模型置信度或教师签审。
- Given 请求仍在等待，When 尝试重复操作，Then 按钮禁用、等待可见，完成后恢复。

### US-04 控制提示出现

作为一名学生，我想收起、关闭及恢复提示，以便独立思考时不被持续打断。

Must；0.5 人日；FR-2.2–2.4、FR-3.2、AC-02/03；原型可演示。

- Given 已有 L1，When 收起，Then 内容隐藏但题目能操作；展开显示同一线索，不额外请求。
- Given 正在练习，When 关闭提示并继续选错，Then 不显示新线索，求助禁用；恢复后可主动求助。
- Given 距上次提示 59 秒或主动预算已达 2，When 再次错误，Then 不自动提示；满 60 秒且预算未用尽才继续评估。

### US-05 用新题独立验证

作为一名学生，我想原题完成后做一道无提示变式题，以便分清辅助完成与独立表现。

Must；0.5 人日；FR-4.1–4.2、AC-04；客户端可演示，服务端阶段保护待开发。

- Given 原题已完成且曾显示线索，When 进入验证，Then 换成不同数值的新题、清空线索、更新路线，禁用求助及提示开关。
- Given 独立构造受保护上下文，When 同时传主动求助、10 次错误和 L5，Then API 返回 SILENCE/L0。
- Given 正在验证，When 连续选错，Then 只给对错及重试反馈，不出现概念线索。

### US-06 区分首次与重试结果

作为一名学生，我想看到练习和验证各自的结果，以便知道这次做对依赖了多少帮助。

Must；0.5 人日；FR-4.3、FR-5.3、AC-05；原型可演示。

- Given 原题用过线索，When 完成，Then 标为使用线索后完成。
- Given 新验证，When 首次选对，Then 标为首次独立通过；Given 首次选错，When 第二次选对，Then 标为第 2 次提交后完成。
- Given 任意完成结果，When 查看，Then 不写成长期掌握或学习效果已提升。

### US-07 失败后保留尝试

作为一名学生，我想服务失败后保留已选答案，以便恢复连接后继续作答。

Must；0.5 人日；FR-5.2、NFR-3、AC-06；原型可演示。

- Given 已选错误答案但未成功提交，When 连接失败或 3 秒超时，Then 中文说明重试方式，选择保留，按钮恢复，失败不增加错误次数。
- Given 上次失败，When 正常重试同一错误答案，Then 只计一次有效错误，不提前触发两次错误提示。
- Given 评审选择等待演示，When 请求未结束，Then 等待状态可见且不能重复提交。

### US-08 教师筛选与回放

作为一名教师，我想按验证结果筛选会话并查看事件顺序，以便检查提示时机和后续表现。

Should；1 人日；FR-6.1–6.2、AC-07；合成交互已实现，真实数据和权限未实现。

- Given 默认 4 个合成会话，When 打开，Then 首次通过显示 2/3、尚未开始显示 1，分母不含未提交验证者。
- Given 选择重试后完成，When 筛选，Then 只有 DEMO-02，首次通过为 0/1；点击可回看首次错误和重试完成。
- Given 选择尚未完成，When 筛选，Then 显示 0/0 和 1 条缺失，不出现 NaN、百分比或班级掌握结论。
- 后续真实验收：跨班级请求返回 403，前端筛选不能替代服务端授权。

### US-09 导出筛选摘要

作为一名教师，我想只导出当前筛选范围的匿名摘要，以便核对统计并减少数据暴露。

Should；0.5 人日；FR-6.3、NFR-5/6；仅合成 CSV 可演示。

- Given 筛选首次通过，When 导出，Then 有 2 行数据，每行标 synthetic，包含会话号、是否使用线索及验证结果。
- Given 任意筛选，When 检查导出，Then 无姓名、学号、草稿、密钥和真实班级信息，页面反馈数量。
- 后续真实验收：服务端重新授权并记录导出；本轮下载不能证明真实权限已完成。

### US-10 可取消地重开

作为一名学生，我想清空前确认是否重开，以便避免误操作丢失本轮结果。

Must；0.5 人日；FR-5.3；第三周补充交互。

- Given 已有选择或结果，When 点重新开始，Then 先说明清空范围，焦点落在保留本轮。
- Given 确认区打开，When 选择保留，Then 选择和结果不变，焦点回入口。
- Given 明确确认，When 重开，Then 回练习初态，清空选择、线索、计数和结果。
