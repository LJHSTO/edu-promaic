# Edu ProMAIC 功能规格说明

## 学生功能

- 课程和章节导航；
- 知识点学习；
- 课堂练习；
- 形成性测验；
- 主动帮助；
- 帮助接受、拒绝和延迟；
- 当前知识点提醒关闭和恢复；
- 支架后的无提示验证；
- 个人学习记录。

## 主动学习功能

- 学习事件采集；
- 学习证据整理；
- Help Need 判断；
- 可打断性判断；
- 不确定性处理；
- 主动介入；
- 保持沉默；
- 支架等级选择；
- 支架升级；
- 支架渐退；
- 冷却和预算；
- 决策原因记录。

## 教师与研究控制台

- 课程结构查看；
- 知识点管理；
- 常见误解管理；
- 支架内容审核；
- 决策回放；
- 介入和沉默分析；
- 学生帮助行为分析；
- 独立学习结果分析；
- 匿名数据导出。

## 受保护测量

在独立验证、迁移和保持测量阶段：

- 不主动展示支架；
- 不泄露答案；
- 不根据测量过程自动升级帮助；
- 记录测量阶段和缺失状态。

## 非功能需求

### 可解释性

每次决策记录：

- 当前课程和知识点；
- 触发证据；
- 证据强度；
- 时机判断；
- 选择的动作；
- 支架等级；
- 实际展示结果；
- 学生后续响应。

### 安全性

- 学生只能访问自己的学习记录；
- 教师只能访问授权课程；
- 研究数据应去标识化；
- 不提交 API 密钥和个人数据。

### 可靠性

- 决策失败时默认保持沉默；
- Agent 超时时不阻塞普通学习流程；
- 学生关闭后不得重复展示；
- 决策能够被回放。
