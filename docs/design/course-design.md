# 大学新生微积分课程设计

## 课程定位

面向本科一年级学生的大学微积分入门课程，重点帮助学生从“套用计算步骤”过渡到“理解概念、表征和方法选择”。

## 课程模块

1. 函数与数学表征；
2. 极限与连续；
3. 导数与变化率；
4. 积分与累积。

## 学习活动

```text
教师讲解
→ 引导练习
→ 学生独立尝试
→ 形成性检查
→ 主动帮助或保持沉默
→ 无提示验证
→ 课后复习
```

## 首期内容原则

- 以概念理解和表征转换为主；
- 不把完整答案作为默认帮助；
- 每个知识点配置常见误解；
- 每个支架回合配置验证任务；
- 正式测量阶段不提供主动提示。
