# 课堂与决策接口说明

## 1. 服务与页面

默认地址为 `http://127.0.0.1:3000`。课堂入口为 `/` 和 `/classroom/`，旧练习入口为 `/index.html`，第三周原型入口为 `/prototype/`。健康接口为 `GET /api/health`。

## 课前预习接口

演示配置接受回环连接，使用匿名会话。受保护配置接受 HTTPS 机构令牌及同源机构 Cookie，并按 `?class=班级编号` 确定班级。省略时使用部署配置的默认班级。成功响应为 `{ "success": true, "data": ... }`。 [安全与部署](security.md)

| 方法和路径 | 响应数据 |
|---|---|
| `GET /api/classroom` | `published` 与 `lesson`，含主题、目标、预习任务和来源 |
| `POST /api/classroom/publish` | 发布所选固定课，返回发布状态与课程；重复发布返回当前状态 |
| `POST /api/classroom/sessions` | 发布后创建学习会话，返回 201 与会话视图。可用 `Idempotency-Key` 重试同一次创建，返回该会话当前状态 |
| `GET /api/classroom/sessions/:id` | 恢复会话，返回当前阶段、题目选项、反馈、提示、结果和 `revision` |
| `POST /api/classroom/sessions/:id/events` | 执行作答或练习提示操作，返回最新会话 |
| `GET /api/classroom/teacher` | 发布状态、全班汇总和最近 20 个会话的事件时间线，含点值误选及智能体运行记录 |
| `GET /api/classroom/teacher/export` | 下载本班结果的 UTF-8 CSV，受保护配置要求本班教师身份并记录导出操作 |
| `GET /api/classroom/audit` | 受保护配置的审计员可读取本班当前分段的最近 50 条审计元数据 |

事件使用 `application/json`，上限 16 KiB。示例：

```json
{"eventId":"demo-01","revision":0,"action":"answer","choice":"a"}
```

`action` 可取 `answer`、`help`、`toggle-help`。仅 `answer` 传 `choice`。新会话从版本 `0` 开始，每接受一次新事件递增一版。原样重传已执行事件返回当前版本，同一 ID 改写、旧版本新事件及阶段不允许的操作返回 409。练习答对后立即切换到独立验证，验证阶段仅接受作答。答案、判分、提示门控和验证结果由服务端维护。

提示包含 `level`、`text` 和 `source`。使用课包的提示附带 `citations`，深层线索可附上数值工具的 `example`。`trace` 提供运行结果、实际步骤、工具名和来源编号。教师回放中的 `event.agent` 使用相同结构。服务端在编排结束后重新核对会话版本，避免过期提示进入验证题。

教师汇总的 `verificationStarted` 计至少提交一次验证的会话，作为 `firstPass` 的分母。`retryPass` 计重试通过，`notSubmitted` 计没有提交验证的会话。`pointValuePractice` 和 `pointValueVerification` 分别计两个阶段至少一次选择点值的会话。`usedHint` 计服务端曾发出提示的会话。

导出的 CSV 每行包含会话编号、练习次数、是否发出提示、验证次数和验证状态。状态可取 `first_pass`、`retry_pass`、`attempted_not_passed` 和 `not_submitted`。受保护配置下，未经认证返回 401、角色或班级无权返回 403，其他学生的会话按 404 处理。

## 2. 评估请求

演示配置开放 `POST /api/decision/evaluate`。媒体类型为 `application/json`，请求体上限为 16 KiB。根节点必须是对象。

| 字段 | 类型 / 默认值 | 含义 |
|---|---|---|
| consecutiveErrors | 非负整数 / 0 | 当前题连续错误次数 |
| pauseSeconds | 非负有限数值 / 0 | 停顿秒数，仅作背景信号 |
| inProtectedAssessment | 布尔值 / false | 是否在无提示验证 |
| userOptedOut | 布尔值 / false | 是否关闭本题提示 |
| isActivelyWorking | 布尔值 / false | 是否正在有效输入 |
| requestedHelp | 布尔值 / false | 是否学生显式求助 |
| interventionsUsed | 非负整数 / 0 | 本题自动提示次数 |
| secondsSinceLastIntervention | 非负有限数值或 null / null | 距上次提示秒数；null 表示尚无提示 |
| currentLevel | 0–5 整数 / 0 | 当前已显示的提示等级 |
| misconceptionType | ≤100 字符的字符串或 null / null | 题库标注的误解类型，不单独触发提示 |

未知字段不参与规则评估，不存储。字符串 `"false"`、`"2"` 不会自动转成布尔值或整数。当前接口不替调用方维护状态。

## 3. 响应

成功返回 200：`{ "success": true, "data": { "action": "...", "level": 0, "reasonCode": "...", "reason": "..." } }`。

| reasonCode | 动作 | 条件 |
|---|---|---|
| PROTECTED_ASSESSMENT | SILENCE / L0 | 独立验证，优先于所有其他条件 |
| USER_OPTED_OUT | SILENCE / L0 | 已关闭提示 |
| ACTIVE_WORK | SILENCE / L0 | 正在有效输入且没有显式求助 |
| REQUESTED_HELP | INTERVENE / L1–L5 | 学生求助，增加一层，最高 L5 |
| BUDGET_EXHAUSTED | SILENCE / L0 | 主动提示预算用尽 |
| COOLDOWN | SILENCE / L0 | 两次提示间隔不足 |
| REPEATED_ERRORS | INTERVENE / L1–L5 | 连续错误达到阈值，增加一层 |
| INSUFFICIENT_EVIDENCE | SILENCE / L0 | 只有长停顿，证据不足 |
| OBSERVE | SILENCE / L0 | 暂无介入条件 |

错误响应为 `{ "success": false, "error": "中文说明" }`。

| 状态码 | 情况 |
|---|---|
| 400 | 无效 JSON、非对象或字段类型与范围错误 |
| 404 | 路由不存在 |
| 405 | 决策接口使用了非 POST 方法，Allow 为 POST |
| 413 | 请求体超过 16 KiB，按 UTF-8 字节计数 |
| 415 | 媒体类型不是 application/json |
| 500 | 内部错误或页面资源无法读取，不输出内部堆栈 |

## 4. 安全与扩展边界

演示规则接口直接评估传入的上下文。课前预习通过会话接口维护服务端阶段、判分和提示预算。
