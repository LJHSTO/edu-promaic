# 决策接口说明

## 1. 服务与页面

默认地址为 `http://localhost:3000`。静态资源开放 `/`、`/index.html`、`/app.js`；健康接口为 `GET /api/health`。默认只绑定本机，没有账户认证或班级数据存储。

## 2. 评估请求

`POST /api/decision/evaluate`，媒体类型为 `application/json`，请求体上限为 16 KiB。根节点必须是对象。

| 字段 | 类型 / 默认值 | 含义 |
|---|---|---|
| consecutiveErrors | 非负整数 / 0 | 当前题连续错误次数 |
| pauseSeconds | 非负有限数值 / 0 | 停顿秒数，仅作背景信号 |
| inProtectedAssessment | 布尔值 / false | 是否在无提示验证 |
| userOptedOut | 布尔值 / false | 是否关闭本题提示 |
| isActivelyWorking | 布尔值 / false | 是否正在有效输入 |
| requestedHelp | 布尔值 / false | 是否学生显式求助 |
| interventionsUsed | 非负整数 / 0 | 本题自动提示次数 |
| secondsSinceLastIntervention | 非负有限数值或 null / null | 距上次提示秒数；null 表示尚无提示 |
| currentLevel | 0–5 整数 / 0 | 当前已显示的提示等级 |
| misconceptionType | ≤100 字符的字符串或 null / null | 题库标注的误解类型，不单独触发提示 |

未知字段不参与规则评估，不存储。字符串 `"false"`、`"2"` 不会自动转成布尔值或整数。当前接口不替调用方维护状态。

## 3. 响应

成功返回 200：`{ "success": true, "data": { "action": "...", "level": 0, "reasonCode": "...", "reason": "..." } }`。

| reasonCode | 动作 | 条件 |
|---|---|---|
| PROTECTED_ASSESSMENT | SILENCE / L0 | 独立验证，优先于所有其他条件 |
| USER_OPTED_OUT | SILENCE / L0 | 已关闭提示 |
| ACTIVE_WORK | SILENCE / L0 | 正在有效输入且没有显式求助 |
| REQUESTED_HELP | INTERVENE / L1–L5 | 学生求助，增加一层，最高 L5 |
| BUDGET_EXHAUSTED | SILENCE / L0 | 主动提示预算用尽 |
| COOLDOWN | SILENCE / L0 | 两次提示间隔不足 |
| REPEATED_ERRORS | INTERVENE / L1–L5 | 连续错误达到阈值，增加一层 |
| INSUFFICIENT_EVIDENCE | SILENCE / L0 | 只有长停顿，证据不足 |
| OBSERVE | SILENCE / L0 | 暂无介入条件 |

错误响应为 `{ "success": false, "error": "中文说明" }`。

| 状态码 | 情况 |
|---|---|
| 400 | 无效 JSON、非对象或字段类型与范围错误 |
| 404 | 路由不存在 |
| 405 | 决策接口使用了非 POST 方法，Allow 为 POST |
| 413 | 请求体超过 16 KiB，按 UTF-8 字节计数 |
| 415 | 媒体类型不是 application/json |
| 500 | 内部错误或页面资源无法读取，不输出内部堆栈 |

## 4. 安全与扩展边界

客户端能提供错误计数、提示等级和保护标志，所以此接口不是可信的考试判定服务。后续会话模块应从服务端状态构建上下文，拒绝客户端解除保护或修改预算，并为教师记录规则版本和原始特征快照。
