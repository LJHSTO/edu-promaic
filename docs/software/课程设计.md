# 课程内容与审核计划

首个演示只覆盖“极限与函数值”。完整微积分课程按以下单元逐步扩展，不将目录规划当成现成题库。

| 单元 | 学习目标 | 需要覆盖的误解 | 验证方式 |
|---|---|---|---|
| 函数与数学表征 | 区分定义域和值域，能在公式、图像和文字之间转换 | 把图像上的点误认为整个函数，忽略定义域限制 | 改变表征的无提示任务 |
| 极限与连续 | 理解趋近、左右极限和连续条件 | 把极限当点值，只检查单侧趋势 | 同概念变式题与概念解释 |
| 导数与变化率 | 区分平均变化率和瞬时变化率，解释导数的几何意义 | 把割线斜率当作切线斜率，忽略变化率单位 | 新函数或实际变化场景 |
| 积分与累积 | 解释定积分与累积量，理解基本定理的使用条件 | 把有向面积当普通面积，机械套公式 | 不同表征下的累积任务 |

每个课程包至少包含知识点编号、目标、题目与标答、错误选项标注、L1–L5 提示、无提示验证题和内容版本。发布前由教师逐条检查题目正确性、提示边界、验证题是否考查同一概念；不把同一道题换成相同答案当成迁移测量。

设计继续围绕六个维度：观察哪些学习证据、何时提示或沉默、提示有多强、用什么表征、学生如何控制、如何收集独立学习证据。前四个影响题目和策略，后两个必须体现在操作与结果记录里。

课堂试用前明确参与者同意、采集字段和保存期限。即时答对、首次验证、近迁移、表征迁移和延迟保持分别报告。没有试用数据时，只提交内容审核与工程验证结果。
