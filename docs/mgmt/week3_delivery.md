## 3. UX 自评

按课件第 54 页的 17 项检查点逐项记 0/1，不静默删除不适用项。第 55 页建议总分 ≥80%；得分只对应原型走查，不代表用户满意度或教师批准。

| 检查项 | 得分 | 检查位置 |
|---|---|---|
| 状态可见 | 1 | 等待、成功、失败和路线 |
| 贴近真实 | 1 | 题目、线索、独立验证措辞；技术演示设置单独折叠 |
| 用户可控 | 1 | 收起、关闭、恢复、取消重置 |
| 一致性 | 1 | 两视图按钮、卡片、导航 |
| 防错 | 1 | 未选提醒、防重、清空确认 |
| 识别优于回忆 | 1 | 选项、路线、本轮结果 |
| 高效 | 1 | Space 选择、Enter 提交 |
| 极简 | 1 | 来源与评审设置折叠 |
| 错误可恢复 | 1 | 失败保留选择、正常重试 |
| 边界声明 | 1 | 原型、合成数据、效果边界 |
| 来源可追溯 | 1 | 固定模板 limit-v1、设计依据和待审核状态可展开 |
| 风险分级 | 0 | 已有保护阶段与清空确认，但尚未由教师确认教学内容风险分级，保守不计分 |
| 拦截可理解 | 1 | 验证阶段说明不提供提示，保留重新作答 |
| 等待可感知 | 1 | 等待文字、1.2 秒等待与 3 秒超时演示 |
| 隐私透明 | 1 | 不采集身份、不保存、教师合成提示和 CSV 标识 |
| 无障碍 | 1 | 标签、焦点、文字状态、键盘；仅为本轮基础自评，不代表完整无障碍认证 |
| 响应式 | 0 | 已写 1100/700px 媒体查询和可折叠路线；320px 实测待补 |

自评 **15/17 = 88.2%**，达到课程原型自评门槛。未通过项保留在表内；正式学生试用前补移动端检查和教师内容风险审核。
