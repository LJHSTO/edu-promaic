# GitHub 协作流程

项目用 [任务看板](https://github.com/users/LJHSTO/projects/1/views/3)跟踪工作，用 [Milestones](https://github.com/LJHSTO/edu-promaic/milestones)安排迭代，用 [Issues](https://github.com/LJHSTO/edu-promaic/issues)记录需求与缺陷。

## 任务流转

待整理 → 待办 → 进行中 → 待评审 → 已完成。每项工作关联 Issue 或 PR，设置负责人、标签与里程碑。新 Issue 自动加入项目；PR 合并或 Issue 关闭后，卡片进入已完成。重复和取消事项在关闭时注明原因。

[迭代排期](https://github.com/users/LJHSTO/projects/1/views/4)按 Milestone 分组，集中显示任务、负责人和状态。当前重点是学习会话与事件记录，以及课程包和教师权限。

## 缺陷处理

使用缺陷表单记录环境、复现步骤、预期结果和实际结果，添加 bug 与优先级标签。修复 PR 使用 `Fixes #编号` 关联问题；部分改进使用 `Refs #编号`。合并前完成代码检查、相关测试和文档更新。

## 沟通与复盘

日常同步记录已完成、下一步和阻塞；迭代评审查看可运行成果与验收结果；复盘保留具体问题和下一轮行动。详见[沟通计划](communication_mgmt_plan.md)、[迭代计划](迭代计划.md)与[复盘记录](../retrospection/README.md)。
