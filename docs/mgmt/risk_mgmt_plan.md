# 风险管理计划

修订日期：2026-10-13。风险在每轮计划和评审时更新，发生后的事实单独进入复盘。

| 编号 | 风险 | 概率 / 影响 | 触发信号 | 处理与验证 | 跟踪责任 |
|---|---|---|---|---|---|
| RSK-01 | 停顿被误判为困难，提示打断推导 | 中 / 中 | 仅因为停留时间出现提示；学生收起后马上重现 | 停顿不单独触发；60 秒冷却、单题 2 次预算；轨迹测试加试用反馈 | 当前 LJHSTO，认领后更新 |
| RSK-02 | 提示泄露原题答案或验证仍可求助 | 中 / 高 | 提示含完整解法；保护请求返回介入 | 模板人工审核；保护优先于所有求助；下一轮由服务端保存阶段 | 核心模块负责人待认领 |
| RSK-03 | 演示被误当成完整教学系统 | 高 / 中 | README 写了未实现的教师端或数据能力 | 所有功能标注状态；明确浏览器内判分、刷新重置和本机用途 | 文档维护者 LJHSTO |
| RSK-04 | 个人数据出现在公共仓库或匿名导出可被重识别 | 低 / 高 | 加入姓名学号、草稿或身份映射；小样本导出 | 当前不采集身份；上线前权限隔离、最小字段、期限删除与导出评审 | 数据模块负责人待认领 |
| RSK-05 | 接口或网络失败使练习无法继续 | 中 / 中 | 请求一直等待、失败提交重复计数 | 3 秒客户端超时、保留选择、显式重试、接口防护与故障走查 | 应用模块负责人待认领 |
| RSK-06 | 进度分散、成员未接受邀请或看板无人维护 | 中 / 中 | 任务无负责人、进行中超额、里程碑到期无验收 | 看板关联真实 issue，成员认领，阻塞项每周同步；邀请接受状态另查 | 项目负责人 LJHSTO |
| RSK-07 | 用即刻正确率代替学习效果 | 中 / 高 | “提示后做对”被写成掌握或迁移提升 | 区分辅助完成、首次验证和重试；后续再测迁移与保持 | 教学评审与维护者 |
| RSK-08 | 可选模型超时或输出越界 | 启用后评估 / 高 | 超过 3 秒、偏离审核模板或带身份信息 | 上线前增加超时降级和内容审核，模型不控制保护状态 | 模型接入负责人待认领 |

当前没有外部模型调用和数据存储；相应风险应在引入模块前重新评估。关键词扫描不能保证提示不泄题，普通 JSON 日志也不能宣称“不可篡改”。未完成的控制措施不得写成现有保障。
