# 风险管理计划

修订日期：2026-11-12。风险在每轮计划和评审时更新，发生后的事实单独进入复盘。负责人与[沟通计划](communication_mgmt_plan.md)第 1 节的分工一致，进展在对应 Issue 中同步。

| 编号 | 风险 | 概率 / 影响 | 触发信号 | 处理与验证 | 跟踪责任 |
|---|---|---|---|---|---|
| RSK-01 | 停顿被误判为困难，提示打断推导 | 中 / 中 | 仅因为停留时间出现提示；学生收起后马上重现 | 停顿不单独触发；60 秒冷却、单题 2 次预算；轨迹测试加试用反馈 | LJHSTO |
| RSK-02 | 提示泄露原题答案或验证仍可求助 | 中 / 高 | 提示含完整解法；保护请求返回介入 | 模板人工审核；保护优先于所有求助；服务端保存阶段，伪造 phase 的测试纳入 #8 | POP350 |
| RSK-03 | 演示被误当成完整教学系统 | 高 / 中 | README、视频或展示把目标架构说成已实现 | 功能标注状态；说明视频是界面演示，LangGraph、RAG 与 PostgreSQL 仍在实施 | LJHSTO |
| RSK-04 | 个人数据出现在公共仓库或匿名导出可被重识别 | 低 / 高 | 加入姓名学号、草稿或身份映射；小样本导出 | 只用合成数据；班级 A/B 授权矩阵与跨班级拒绝测试纳入 #9；导出前最小字段评审 | BBmonster1 |
| RSK-05 | 接口或网络失败使练习无法继续 | 中 / 中 | 请求一直等待、失败提交重复计数 | 3 秒客户端超时、保留选择、显式重试；eventId 唯一键和失败回滚纳入 #8 | wmm228 |
| RSK-06 | 进度分散、成员未接受邀请或看板无人维护 | 中 / 中 | 任务无负责人、进行中超额、里程碑到期无验收 | 看板关联真实 Issue；每周同步写入 Issue 评论；邀请接受状态另查 | pedri25（看板）、LJHSTO（协调） |
| RSK-07 | 用即刻正确率代替学习效果 | 中 / 高 | “提示后做对”被写成掌握或迁移提升 | 区分辅助完成、首次验证和重试；统计分母测试纳入 #9 | pedri25 |
| RSK-08 | 模型超时或输出越界 | 启用后评估 / 高 | 首条提示超过 8 秒；引用不在本次检索结果中；偏离审核模板 | 一次运行最多 20 秒、4 次工具调用、2 次补查；引用校验失败时回退审核内容；先用假模型响应测回退（#9） | BBmonster1 |
| RSK-09 | 迭代 3 任务延期 | 高 / 中 | 子目标到期仍未开始；#9 等待 #8 | #8 已触发：11-11 子目标未开始，顺延至 11-16；仍未完成时缩到单题，#9 先做不依赖数据库的 Schema 与授权部分 | LJHSTO |
| RSK-10 | PostgreSQL、pgvector 与 LangGraph 学习成本超出预期 | 中 / 中 | PoC 卡在环境搭建或驱动选型超过 2 天 | 先用合成数据和最小 PoC；每周同步报告阻塞；必要时保留本机规则服务作为演示路线 | wmm228 |

当前仓库仍没有外部模型调用和数据库存储；相应风险在模块接入前重新评估。关键词扫描不能保证提示不泄题，普通 JSON 日志也不能宣称“不可篡改”。未完成的控制措施不得写成现有保障。
