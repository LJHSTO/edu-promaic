## 验证

`npm run check` 执行语法检查；`npm test` 运行规则与 HTTP 接口测试。GitHub Actions 使用 Node.js 22 / 24、Windows / Linux 矩阵。交互检查覆盖提示控制、独立验证、网络失败恢复、320px 布局和键盘操作。
