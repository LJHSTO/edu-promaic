# Edu ProMAIC 评测计划

## 工程指标

- 决策是否稳定；
- 日志是否完整；
- 决策是否可回放；
- 学生关闭后是否停止提示；
- 受保护测量是否零介入；
- 数据是否跨学生隔离。

## 过程指标

- 介入率；
- 沉默率；
- 错误介入率；
- 接受、拒绝和忽略比例；
- 支架升级次数；
- 独立尝试；
- 错误重复率。

## 学习指标

- 无提示近端验证；
- 新题型迁移；
- 跨表征迁移；
- 延迟保持；
- 独立概念解释；
- 独立方法选择。

## 体验指标

- 提示时机是否合适；
- 是否产生打断；
- 学生是否感到能够控制帮助；
- 教师是否能够理解决策原因。
